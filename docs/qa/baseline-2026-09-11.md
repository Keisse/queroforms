## Regra do autopilot

A partir deste baseline, cada fase deve:

1. alterar apenas o necessario para a fase;
2. adicionar ou atualizar testes que representem o comportamento esperado;
3. executar os testes antes do build;
4. manter o build verde;
5. verificar Supabase quando houver mudanca relacionada a banco/configuracao;
6. confirmar o deploy do commit final da fase antes de considera-la concluida.

Mudancas que exigirem decisao de negocio nao devem ser inventadas. O autopilot deve interromper apenas naquele ponto especifico, preservando as correcoes tecnicas que possam ser feitas sem ambiguidade.
